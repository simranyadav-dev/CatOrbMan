# 🐱 CatOrb Man 

Welcome to **CatOrb Man** – a fun and creative web game project built as part of my freelance work demos.  
This repository is meant to showcase my development style, code quality, and project execution skills for potential clients.  

---

## 🔎 About CatOrb Man
- 🎮 A browser-based game inspired by classic arcade mechanics.  
- 🐾 Features a unique **cat character** navigating orbs and challenges.  
- 🛠️ Built using:
  - HTML, CSS, JavaScript (Vanilla)  
  - Styling : Tailwind CSS
- 🎯 Focuses on smooth animations, modular code, and engaging UI.
